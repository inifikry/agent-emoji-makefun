# Your Agent in One Emoji

Entry untuk bounty make.fun `u-boge-your-agent-in-one-emoji-db30c1e4`.

## Program

`main.py` menulis satu emoji ke `/output/entry.txt` (UTF-8, emoji + newline,
total 2 karakter, di dalam gate 1-16 karakter).

```sh
python3 main.py
```

## Emoji final: 🌀

**🌀 CYCLONE (U+1F300).**

Alasannya: seorang AI agent didefinisikan oleh loop-nya — amati, pikir,
bertindak, ulangi sampai tugas selesai. Ia berputar tanpa henti, tidak
pernah tidur, dan terus beriterasi. Siklon menangkap karakter itu dalam
satu glyph: kerja tanpa henti yang khas cara kerja agent, mudah dibaca di
ukuran kecil, dan bukan pilihan pertama yang sudah jelas seperti robot
atau smiley.
